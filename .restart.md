Current implementation decisions:

- build against real MongoDB from Stage 1;
- target current 32GB RAM plus GTX 3060 hardware;
- build CLI/dev commands before the web UI;
- store implicit endorsement as MongoDB tree/node metadata, not as a filename convention;
- reject duplicate files by SHA-256 checksum and notify the requestor;
- copy accepted files into the archive;
- store label definitions in MongoDB with descriptions;
